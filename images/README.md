# images/

Drop photos here and the page picks them up.

| File | Where it appears | Shoot notes |
|---|---|---|
| `robot.jpg` | "About us" section, and the link preview when the site is pasted into Discord | 16:9, about 1600px wide |
| `work-01.jpg` … `work-03.jpg` | "Photos" section | 4:3, about 1200px wide |

The page hides the robot figure automatically if `robot.jpg` isn't here yet, so
nothing breaks before you add it.

Compress before committing. A 4MB phone photo makes the page crawl on venue wifi;
1600px wide at ~70% JPEG quality is usually under 300KB and looks identical.
